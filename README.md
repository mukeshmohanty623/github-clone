# GitHub Clone

🚀 **GitCloneHub** is a GitHub repository homepage clone built using **Next.js, Tailwind CSS, and Shadcn UI**. The project focuses on **pixel-perfect UI**, accessibility, responsiveness, and real-time data integration with GitHub APIs.

## 🌟 Features

- **Pixel-perfect UI** replicating GitHub's repository homepage.
- **GitHub API Integration** to fetch real-time repository data, commits, and more.
- **Markdown Rendering** using Markdoc for proper display of documentation files.
- **Server-side Rendering (SSR)** with Next.js for optimized performance.
- **Fully Responsive** and accessible design using Tailwind CSS.
- **Modern UI Components** with Shadcn UI for a polished look.

## 🛠️ Tech Stack

- **Framework**: Next.js
- **Styling**: Tailwind CSS
- **UI Components**: Shadcn UI
- **API Integration**: GitHub REST API
- **Markdown Handling**: Markdoc

## 🚀 How to Use

You can explore different repositories by modifying the URL pattern:

```md
https://gitclonehub.vercel.app/:orgname/:reponame
```

Example:

```md
https://gitclonehub.vercel.app/facebook/react
```

## 📥 Installation & Setup

1. **Clone the repository:**
   ```sh
   git clone https://github.com/yourusername/gitclonehub.git
   cd gitclonehub
   ```
2. **Install dependencies:**
   ```sh
   npm install
   ```
3. **Create a ******\`\`****** file and add your GitHub API key:**
   ```sh
   NEXT_PUBLIC_GITHUB_API_KEY=your_github_api_key
   ```
4. **Run the development server:**
   ```sh
   npm run dev
   ```
5. **Open the app in your browser:**
   ```
   http://localhost:3000
   ```
